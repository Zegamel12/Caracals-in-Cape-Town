# Caracals in Cape Town

This project explores caracal activity and movement patterns in Cape Town using wildlife tracking data and data visualization. It features an automated Python pipeline that processes tracking data, generates visualizations and animations, and presents the results through an interactive Streamlit dashboard.

The project aims to make wildlife movement data easier to explore and understand, supporting insights into caracal behaviour and their use of urban and natural environments.

**Technologies:** Python, data processing, geospatial analysis, data visualization, animation, Streamlit, and Pixi.
