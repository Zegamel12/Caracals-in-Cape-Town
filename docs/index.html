Caracals in Cape Town

Exploring how roads, urbanisation and time of day relate to caracal movement using GPS tracking data and statistical modelling.

Explore the code

About the project

This project analyses caracal GPS observations and their relationship with road proximity, landscape type and day-night patterns. A reproducible Python pipeline processes the data and generates statistical analyses and visualisations.

Research questions

  • Does movement speed vary with distance from roads?
  • Does this relationship differ between urban areas and wildland?
  • Does the relationship change between day and night?

Methods and tools

Python · GPS tracking · GIS · OpenStreetMap · Geospatial analysis · Mixed-effects models · Interactive visualisation
